If you do want to be able to play this game you can find it [here](https://static-eulogy-studios.itch.io).

Mechanics included in the game; A* pathfiding with random roam based on distance from player, Graph based procedural generation, swapable weapons, multiple attack types, health/mana systems, difficulty systems, level difficulty scaling, item pickups, randomised drops/weight based loot system.

This game was made as a project for a module pertaining to procedural generation and pathfinding within games. More specifically this game uses, graph procedural generation with A* pathfinding for the enemies. This project was made in Unity 6 2D, using C# scripts allowing me full control over all of the specific parts of my code; Also making it easy for me to set certain variables to be changeable quickly in editor to find the right number for any given value. This was my first project unity and I certainly learnt a lot from it, mostly stuff like chaining scripts together, scriptable objects, how procedural generation itself works, pathfinding optimization and manager scripts and their uses and why we dont necessarily use them any more.

It also made me realise that coding was gonna be a lot harder than I originally thought but however would lead to a satisfying result for a game knowing that most of it was coded by my own hands. And while i was given 13 weeks to make this game prototype I did end up leaving it till quite late to cram it all in like most other students. Although despite this I feel as if the resulting end was quite good and fits the brief almost to a "T" but I did miss out making the prototype having customisble generation for hand in and instead focused on the publishable version too much. However making the generation tweakable by the player does give more difficulty settings for them to change by themselves.
