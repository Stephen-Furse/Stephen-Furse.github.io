This game was made as a project for a module pertaining to procedural generation and pathfinding within games. More specifically this game uses, graph procedural generation with A* pathfinding for the enemies. This project was made in Unity 6 2D, using C# scripts allowing me full control over all of the specific parts of my code; Also making it easy for me to set certain variables to be changeable quickly in editor to find the right number for any given value. This was my first project unity and I certainly learnt a lot from it, mostly stuff like chaining scripts together, scriptable objects, how procedural generation itself works, pathfinding optimization and manager scripts and their uses.

If you do want to be able to play this game you can find it [here](https://static-eulogy-studios.itch.io).

Mechanics included in the game; AI pathfiding, Graph based procedural generation, swapable weapons, multiple attack types, health/mana systems, difficulty systems, level difficulty scaling, item pickups, randomised drops/weight based loot system.
